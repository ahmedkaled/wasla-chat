# وصلة WASLA — نسخة أولية (Alpha)

هذا مشروع Android Studio أولي لتجربة شات نصي محلي بدون إنترنت باستخدام TCP على شبكة Wi‑Fi أو Hotspot.

## الموجود حاليًا
- استضافة شات على المنفذ TCP 8988.
- اتصال الأجهزة بالمضيف عن طريق عنوان IP.
- رسائل نصية يرسلها المضيف وتصل للعملاء، ورسائل العملاء يتم بثها إلى المتصلين.

## غير مكتمل في هذه النسخة
- اكتشاف الأجهزة تلقائيًا.
- إرسال الصور والملفات والرسائل الصوتية.
- المكالمات الصوتية.
- التشفير والتحقق من الهوية وإعادة الاتصال.
- الاختبارات على أجهزة فعلية.

لا تستخدم هذه النسخة لمعلومات خاصة؛ الاتصال غير مشفر، وهي نموذج أولي فقط.

## بناء APK عبر Android Studio
1. ثبّت Android Studio على كمبيوتر، مع Android SDK Platform 35.
2. افتح مجلد المشروع `wasla_android` عبر File > Open.
3. وافق على مزامنة Gradle وانتظر تنزيل إضافات البناء.
4. من Build اختر Build APK(s).
5. بعد نجاح البناء، سيظهر APK عادة داخل `app/build/outputs/apk/debug/`.

## تجربة الشات
1. وصّل كل الأجهزة بنفس الراوتر، أو فعّل Hotspot على جهاز واتصل به من بقية الأجهزة.
2. افتح التطبيق على الجهاز المضيف واضغط «استضافة شات».
3. اعرف عنوان IP المحلي للجهاز المضيف من إعدادات شبكة Wi‑Fi/Hotspot. عنوان نقطة الاتصال يختلف حسب الهاتف؛ لا تفترض أنه دائمًا 192.168.43.1.
4. اكتب عنوان IP في الأجهزة الأخرى واضغط «اتصال بالمضيف».
5. يجب السماح بالاتصال على المنفذ TCP 8988 داخل الشبكة المحلية.

ملاحظة: بعض إصدارات أندرويد/الشركات قد تمنع اتصال الأجهزة بالعملاء المتصلين عبر Hotspot أو تعزل الأجهزة؛ حينها جرّب راوترًا محليًا يسمح باتصال الأجهزة ببعضها.
